# Part 4: Locators and Actions

## Goal

By the end of this lecture, viewers should understand Playwright locators, navigation, click, fill, select, keyboard, hover.

## Suggested Demo Flow

1. Explain the topic in plain language.
2. Open the relevant feature, step, support, page or API file.
3. Show the important code path without over-explaining every character.
4. Run the matching Cucumber command.
5. Explain what passed, what could fail, and what viewers should practice.

## Beginner Talking Points

- Playwright performs the browser and API automation.
